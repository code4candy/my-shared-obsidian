
## Es gibt mehrere Tools:

### 1. Im Vergleich

| Tool                 | Typ                                                                                  | Open Source       | Sprache            | Hauptziel                                      |
| -------------------- | ------------------------------------------------------------------------------------ | ----------------- | ------------------ | ---------------------------------------------- |
| **Obsidian publish** | https://help.obsidian.md/publish                                                     | -                 | -                  | 10$ / Monat                                    |
| **Quartz**           | Static Site Generator speziell für Obsidian<br>https://quartz.jzhao.xyz/             | ✅ Ja (MIT)        | TypeScript         | Einfaches Veröffentlichen von Obsidian-Notizen |
| **Hugo**             | General Purpose Static Site Generator https://gohugo.io/getting-started/quick-start/ | ✅ Ja (Apache 2.0) | Go                 | Schnelle, flexible Websites & Blogs            |
| **Gatsby**           | React-basiertes Webframework                                                         | ✅ Ja (MIT)        | JavaScript / React | Moderne, interaktive Websites & Apps           |
### 2. Use Cases

| Ziel                                                 | Beste Wahl    | Warum                                                |
| ---------------------------------------------------- | ------------- | ---------------------------------------------------- |
| **Einfach Obsidian online stellen, 1:1 wie Publish** | 🪶 **Quartz** | Speziell für Obsidian gemacht, keine Anpassung nötig |
| **Schöne, schnelle, flexible Website aus Markdown**  | 🐹 **Hugo**   | Schnell, stabil, viele Themes, Open Source           |
| **Moderne Web-App oder interaktive Seite**           | ⚛️ **Gatsby** | React-basiert, maximal flexibel, aber komplexer      |
